### BSc thesis

**Self-Supervised Temporal Representation Learning for Anomaly Detection in Financial Time Series**
Awarded Best Thesis Poster (AI/ML in Finance category). Code: [self-supervised-temporal-anomaly-detection](https://github.com/PretomChandraRoy/self-supervised-temporal-anomaly-detection)

### Selected projects

- [**self-supervised-temporal-anomaly-detection**](https://github.com/PretomChandraRoy/self-supervised-temporal-anomaly-detection): Transformer-based self-supervised representation learning for detecting anomalies in financial time series.
- [**rice-mae-classification**](https://github.com/PretomChandraRoy/rice-mae-classification): Masked autoencoder pre-training with Vision Transformers for microscopic rice grain classification.
- [**rice-type-classification-cnn**](https://github.com/PretomChandraRoy/rice-type-classification-cnn): A custom PyTorch CNN that classifies ten processed rice varieties from microscopic images, using leakage-safe group splitting.
- [**ShopBot**](https://github.com/PretomChandraRoy/ShopBot-AI-Powered-E-Commerce-Chatbot): A conversational storefront built with Next.js, MongoDB, NextAuth and Google Gemini.

### Currently building

[**bn-en-grocery-matching**](https://github.com/PretomChandraRoy/bn-en-grocery-matching): An entity resolution system that matches grocery products across Bangla and English listings, developed with versioned data (DVC) and automated tests. In early development.
